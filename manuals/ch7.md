# 第7章：Appendicesの使い方 — 何を“切る”か

## 🎯 本章の目的

本章では、Appendices（付録）の効果的な活用方法を解説する。付録は「読者の関心に応じてアクセス可能な情報」を提供する場所であり、本文の流れを損なわずに重要情報を補完できる。

---

## 📐 Appendicesの役割と原則

### 1. 本文の読みやすさを優先する

- 技術的・詳細な内容はAppendixに回すことで、本文の論旨を明確に保つ。

### 2. 情報の“重要度 × 専門性”に応じて分離

- コア読者には必要でも、一般読者には過剰な情報はAppendixに分離。

### 3. 本文からの“参照可能性”を担保する

- *"Appendix A shows..."*  
- *"See Appendix C for derivations."*  
  のように、本文からAppendixへの明確なリンクを付ける。

---

## 🧱 Appendicesに入れるべき情報（具体例）

| 内容               | 典型例                                              |
|--------------------|-----------------------------------------------------|
| 数式の導出         | HJBの導出、均衡条件の詳細展開                      |
| ロバストネスの詳細 | 代替推定法、サブサンプル分析                      |
| データの補足記述   | 変数定義、マージ処理、欠損補完方法                |
| 拡張モデル         | セクター追加、政策ルール変更のバリエーション      |
| 図表の完全版       | 本文掲載の簡略版の拡張                             |

---

## ✅ テンプレ文例（本文 → Appendices）

> *"The full derivation of the equilibrium conditions is provided in Appendix A."*

> *"Appendix C shows robustness checks using firm-level data from 2013."*

---

## 📋 書くときのチェックリスト（Appendices）

- [ ] 本文の論旨に集中できる構成になっているか？
- [ ] 技術的・補足的内容がAppendixに適切に分離されているか？
- [ ] Appendixに入れる情報の専門性・重要度は妥当か？
- [ ] 本文中からAppendixが参照可能になっているか？
- [ ] Appendicesに冗長な内容や未整理の情報が含まれていないか？
